# シフトマル（Shiftmaru）- LP Front-end

飲食店・小売店向けのシフト管理SaaS「シフトマル」のサービス紹介ランディングページ（LP）フロントエンドコードです。

## 概要

「シフトマル」は、希望シフトの収集から自動作成、共有、変更連絡までをシームレスに行うシフト管理サービスです。本リポジトリは、サービスの強み、料金プラン、問い合わせ（無料トライアル）フォームを備えた静的LPのソースコードを管理しています。

## 構成・セクション一覧

* **Hero:** メインキャッチコピー、イメージイラスト風UIサンプル、CVボタン（無料体験・デモ）
* **課題（#pain）:** 紙やExcel、LINEでのシフト管理における課題の可視化
* **機能（#features）:** サービスの主要な4つの特徴
* **使い方（HOW IT WORKS）:** 導入までの簡単3ステップ
* **料金（#pricing）:** スモール / スタンダード / マルチ店舗のプラン比較表
* **よくある質問（#faq）:** 導入前の懸念点に対するQ&A
* **無料トライアルフォーム（#signup）:** 申込用フォーム（JavaScriptによる簡易送信完了表示付き）

## 特徴・技術仕様

* **依存ライブラリなし（Pure HTML / CSS / JS）:** 外部フレームワークを使用せず、軽量で高速なレスポンスを実現
* **レスポンシブ対応:** スマートフォン・タブレット・PCの表示サイズに対応（メディアクエリ実装済み）
* **Webフォント:** Google Fonts (`Noto Sans JP`) を使用
* **インタラクション:**
* スムーススクロール実装 (`scroll-behavior: smooth;`)
* クライアントサイドでの簡易フォーム送信擬似処理（JavaScript）



## ローカルでの実行方法

1. リポジトリをローカル環境にクローンします。
```bash
git clone https://github.com/your-username/shiftmaru-lp.git

```


2. ディレクトリに移動します。
```bash
cd shiftmaru-lp

```


3. `index.html` を任意のブラウザで開きます。
